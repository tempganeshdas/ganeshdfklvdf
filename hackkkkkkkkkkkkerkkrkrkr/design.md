# Climate Action Website - Design System

## Design Philosophy

### Color Palette
- **Primary**: Deep Forest Green (#1B4332) - Trust, nature, stability
- **Secondary**: Warm Terracotta (#D4A574) - Earth, warmth, accessibility
- **Accent**: Ocean Blue (#2E86AB) - Water, clarity, technology
- **Neutral**: Soft Stone (#F8F9FA) - Clean, modern, readable
- **Alert Red**: #DC2626 - Warnings, danger zones
- **Success Green**: #059669 - Positive actions, solutions

### Typography
- **Display Font**: "Tiempos Headline" - Editorial authority, environmental gravitas
- **Body Font**: "Inter" - Modern clarity, technical precision
- **Data Font**: "JetBrains Mono" - Code, metrics, precision

### Visual Language
- **Editorial Sophistication**: Inspired by National Geographic and Wired
- **Data-Driven Aesthetics**: Clean charts, readable metrics
- **Environmental Authenticity**: Real imagery, honest representation
- **Human-Centered Design**: Accessible, inclusive, actionable

## Visual Effects & Styling

### Used Libraries
1. **Anime.js** - Smooth micro-interactions and data transitions
2. **ECharts.js** - Environmental data visualizations
3. **Leaflet.js** - Interactive environmental maps
4. **Typed.js** - Dynamic text reveals for statistics
5. **Splide.js** - Image carousels for case studies
6. **p5.js** - Particle systems for atmospheric effects
7. **Splitting.js** - Text animation effects
8. **Matter.js** - Physics-based interactions
9. **Shader-park** - Background environmental effects

### Animation & Effects
- **Scroll Motion**: Subtle reveal animations (16px translation, 200ms duration)
- **Data Transitions**: Smooth chart updates and counter animations
- **Background**: Subtle particle system representing atmospheric conditions
- **Hover Effects**: 3D tilt on cards, glow on interactive elements
- **Text Effects**: Typewriter for key statistics, color cycling for emphasis

### Header Effect
- **Atmospheric Background**: Animated gradient representing sky conditions
- **Floating Particles**: Subtle environmental particles (pollen, dust, snow)
- **Data Overlay**: Real-time environmental metrics with smooth transitions

### Interactive Elements
- **Dashboard Cards**: Hover lift with shadow expansion
- **Map Markers**: Pulse animation for active reports
- **Form Elements**: Focus states with environmental color transitions
- **Buttons**: Morphing background colors with loading states

### Responsive Design
- **Mobile-First**: Optimized for environmental field work
- **High-Contrast**: Accessible in various lighting conditions
- **Touch-Friendly**: Large interactive areas for mobile users
- **Offline-Capable**: Core functionality works without connection

### Environmental Data Visualization
- **Color-Coded Metrics**: AQI, temperature, humidity with standard color schemes
- **Progressive Disclosure**: Layered information architecture
- **Real-Time Updates**: Live data streaming with smooth transitions
- **Historical Context**: Trend analysis with temporal navigation
